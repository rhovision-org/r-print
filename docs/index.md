# r-print

**On-chain newspaper and magazine primitives for rholo, settled through r-cash.**

> **Status:** Foundation in progress. Devnet-only, unaudited. Do not put real value on it.

r-print treats a publication as an organisation rather than a personal brand. A masthead owns
a charter, a roster and an editorial authority. A commission escrows money against milestones,
so a writer can eat and sleep while the work is researched. An article is a provenance record
whose content hash and bylines are committed on-chain. An edition is an ordered, editor-signed
manifest. Corrections append; they never rewrite history.

The book explains the problem, the model, the contracts, the harness, and the honest limits.
Start with [the atomisation problem](orientation/the-atomisation-problem.md), then read
[publication as an organisation](concepts/publication-as-organisation.md).

See [Status, scope and honest limits](orientation/status-and-scope.md) for the labels used
throughout the book. "Implemented" never means "tested", "audited" or "production-ready".
